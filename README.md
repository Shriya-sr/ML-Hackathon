# PathSnap: Distributed Map-Matching & Route Reconstruction

UE24CS352A Machine Learning hackathon · PES University, Department of CSE, RR Campus

PathSnap reconstructs the road route a vehicle actually drove from noisy, gappy GPS fixes. It generates candidate
road segments per fix, scores them with a supervised classifier, and decodes a drivable route with an HMM and
the Viterbi algorithm. The result is served by a FastAPI backend (Laptop 1) to a React evaluator UI (Laptop 2).

```
raw .track/.nodes/.arcs ─► cleaning + UTM projection ─► STRtree candidates (50 m, K=10) ─► 21 features
   ─► HistGradientBoosting P(correct) ─► HMM (classifier emissions + network-distance transitions)
   ─► segmented Viterbi ─► shortest-path route reconstruction ─► FastAPI ─► React/Leaflet UI
                                     server-side only: .route ─► RouteEvaluator ─► aggregate metrics
```

**Results** (all generated by the scripts below; full tables in `experiments/` and the technical report):
see [`reports/final/RESULTS_SUMMARY.md`](reports/final/RESULTS_SUMMARY.md).

## 1. Installation

Python 3.10+ (tested on 3.12.6, Windows 11), Node.js 18+ (tested on 22.19).

```powershell
git clone https://github.com/Shriya-sr/ML-Hackathon.git PATHSNAP
cd PATHSNAP
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
pip install -e .
cd frontend; npm ci; cd ..
```

Dataset: copy the course data into `data/raw/` (see [`data/README.md`](data/README.md)) or set
`$env:PATHSNAP_DATA_DIR`.

## 2. Reproduce the experiments

```powershell
python scripts/run_eda.py                       # inventory, data quality, EDA figures      (~5 min)
python scripts/build_features.py --jobs 6       # candidates + features for train/student_test (~2 min)
python -W ignore scripts/train_all.py --fresh   # 8 models, 5-fold trip-grouped CV + student test (~40 min)
python scripts/feature_analysis.py              # permutation importance + group ablation   (~10 min)
python -W ignore scripts/optimise.py            # Optuna TPE on HistGradientBoosting        (~25 min)
python scripts/tune_hmm.py                      # decoder grid on training trips (OOF probs) (~10 min)
python scripts/evaluate_all.py                  # classifier-only vs HMM on student test     (~2 min)
python scripts/generate_maps.py                 # Folium maps
python scripts/make_report_figures.py           # model comparison figures
python scripts/build_report.py                  # technical report PDF
```

Seeds are fixed (42). The evaluator partition is never read by any of these scripts.

## 3. Tests

```powershell
python -m pytest -p no:warnings                 # unit + edge cases + API (real pipeline on trip 00000052)
cd frontend; npx vitest run; npx tsc -b          # UI tests + type check
```

## 4. Run the system

**Laptop 1 (API):**

```powershell
.\.venv\Scripts\Activate.ps1
python -m backend.main                          # http://0.0.0.0:8000, docs at /docs
```

```powershell
cd frontend
"VITE_API_URL=http://<LAPTOP-1-IP>:8000" | Out-File -Encoding ascii .env.local
```

### API

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/health` | liveness, model loaded?, mode, trip count |
| GET | `/api/system/info` | EVALUATION/DEVELOPMENT mode, partition, versions |
| GET | `/api/model/info` | model variant, feature schema, CV score, HMM parameters |
| GET | `/api/trips` | the trips available for evaluation (no labels) |
| GET | `/api/trips/{id}/metadata` | fixes, duration, bbox, network size, gaps |
| POST | `/api/predict/{id}` | run the full pipeline and return route, per-fix decisions, flags, timings and server-side metrics |
| GET | `/api/results/{id}` | last result for a trip |
| GET | `/api/results/{id}/explain/{fix}` | candidates, probabilities and key features for one fix |

**Evaluator data**: put the 10 reserved trips in `data/raw/evaluator_test/` on Laptop 1 and restart. While that
folder is empty the API serves the student-testing trips in clearly labelled DEVELOPMENT mode. Reference routes
are read only by the server-side `RouteEvaluator`; responses contain aggregate metrics only (enforced by
`backend/tests/test_api.py::test_no_ground_truth_leakage`).
